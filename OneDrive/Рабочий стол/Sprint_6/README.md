Яндекс.Самокат - Автотесты

Автоматизированные тесты для учебного сервиса Яндекс.Самокат (https://qa-scooter.praktikum-services.ru/)

## Описание проекта

Проект содержит автоматизированные тесты для проверки функциональности сервиса Яндекс.Самокат:
- **FAQ тесты** - проверка выпадающего списка "Вопросы о важном"
- **Тесты оформления заказа** - полный позитивный сценарий с двумя точками входа
- **Тесты логотипов** - проверка редиректов и атрибутов

## Технологии

- **Python** - язык программирования
- **pytest** - фреймворк для тестирования
- **Selenium WebDriver** - автоматизация браузера
- **Allure** - генерация отчетов
- **Firefox** - браузер для тестирования

## Установка и запуск

### Предварительные требования

1. Установите Python 3.8+
2. Установите Firefox браузер
3. Selenium автоматически скачает и настроит GeckoDriver

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск тестов

#### Запуск всех тестов
```bash
pytest tests/ -v --alluredir=allure-results
```

#### Запуск тестов FAQ
```bash
pytest tests/test_faq.py -v --alluredir=allure-results
```

#### Запуск тестов заказов
```bash
pytest tests/test_order_flow.py -v --alluredir=allure-results
```

#### Запуск тестов логотипов
```bash
pytest tests/test_logos.py -v --alluredir=allure-results
```

### Генерация отчета Allure

```bash
allure serve allure-results
```

## Описание тестов

### FAQ тесты (10 тестов)
- **test_faq_questions_count** - проверка количества вопросов (8)
- **test_faq_section_visible** - проверка видимости раздела FAQ
- **test_faq_answers** - параметризованный тест для проверки ответов на все 8 вопросов (генерирует 8 отдельных тестов)

### Тесты заказов (2 теста)
- **test_order_scooter_from_header** - полный сценарий заказа через кнопку в хедере
- **test_order_scooter_from_main_page** - полный сценарий заказа через кнопку на главной странице

### Тесты логотипов (4 теста)
- **test_scooter_logo_redirect_from_main_page** - редирект по логотипу Самоката с главной страницы
- **test_yandex_logo_redirect** - редирект по логотипу Яндекса (открытие Дзена)
- **test_scooter_logo_redirect_from_order_page** - редирект по логотипу Самоката со страницы заказа
- **test_logos_attributes** - проверка атрибутов логотипов (href, target="_blank")

## Особенности реализации

### Архитектура
- **Page Object Model** - разделение логики и локаторов
- **BasePage** - базовый класс с общими методами для всех страниц
- **HeaderPage/MainPage** - специфичные Page Objects для главной страницы
- **OrderPage** - Page Object для страницы заказа

### Технические решения
- **Явные ожидания** (WebDriverWait) для стабильности тестов
- **Параметризация** тестов для покрытия разных сценариев
- **JavaScript fallback** для проблемных элементов (календарь, dropdown)
- **Allure отчеты** с подробной документацией каждого шага
- **Обработка динамических элементов** (FAQ аккордеон, календарь, выпадающие списки)
- **Selenium 4** - автоматическое управление драйверами браузеров
